# Workout plan

1. Ask about the goal (strength, endurance, general fitness), current level, available equipment, days per week and minutes per session, and any injuries.
2. Lay out the week: which days, what each session focuses on and rest days.
3. For each session: a warm-up, four to six exercises with sets, reps or time, rest between sets and a cool-down.
4. Explain how to progress over four weeks, and what to do if a session feels too hard.
5. Offer an easier and a harder version of each exercise.

Suggest checking with a doctor first for anyone with an injury, a health condition or who is new to exercise. Stop any exercise that causes pain.
