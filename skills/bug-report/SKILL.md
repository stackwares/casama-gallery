# Bug report

1. Ask what the person was trying to do, what happened instead, and whether it happens every time.
2. Write the report:
   - **Title**: what breaks and where, in under ten words.
   - **Steps to reproduce**, numbered, starting from a clean state.
   - **Expected** and **Actual** behaviour.
   - **Environment**: app version, device, operating system and browser.
   - **Evidence**: error messages copied exactly, screenshots and logs.
   - **Impact**: who is affected and whether there is a workaround.
3. Keep guesses about the cause in a separate **Notes** section.

Offer to add it to the ticket board or open an issue where the team tracks bugs.
