# Proofread

1. Ask which variety of English to follow (US, UK, other) if it isn't clear from the text.
2. Fix spelling, grammar, punctuation and obvious typos. Keep the author's words, style and tone; do not rewrite sentences that are already correct.
3. Point out, without changing, anything that is unclear, repeated or possibly wrong (a date, a name, a number).
4. Return the corrected text in full, then a short **Changes** list grouped by kind, and a **Worth checking** list for the things you flagged.

If the text is long, work section by section and keep headings and formatting exactly as they are.
