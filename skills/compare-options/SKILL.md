# Compare options

1. Ask what the comparison is for and the three to six things that matter most (price, features, support, where it ships). Ask for a budget or hard limits.
2. Gather facts for each option from official pages and recent, reputable reviews. Note the date of any price.
3. Build a table: options as columns, criteria as rows. Use "unknown" rather than guessing.
4. Under the table, give each option's best and worst point in a line.
5. Recommend one for the person's situation and name the runner-up and when it would be better.

Link every source. Say plainly when options are close enough that personal taste should decide.
