# Fact check

1. Pull out every checkable claim: numbers, dates, quotes, names and statements of fact. Skip opinions.
2. For each claim, look for the original source first (the study, the official data, the full quote), then reputable reporting.
3. Mark each claim:
   - **Supported**, with the source.
   - **Wrong**, with the correct fact and source.
   - **Misleading**: true but missing context. Say what is missing.
   - **Unverified**: you couldn't find a reliable source either way.
4. List the claims in the order they appear, one line each, then a short overall verdict.

Never mark a claim supported from memory alone. Link what you read.
